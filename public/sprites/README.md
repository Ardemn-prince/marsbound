# MarsBound sprite atlas v1

Asset: `public/sprites/mars-atlas-v1.png` (1254 × 1254 RGBA, transparent).
Generated using the built-in imagegen tool with the two user-supplied reference images. No external asset pack dependency.

Runtime: four equal columns and rows, sampled using natural image dimensions. Canvas smoothing is disabled. Original code-drawn art remains as a loading/failure fallback. Astronaut/Rex use four walk frames and mirrored left/right facing; idle uses frame 4. The selected cadet retains their colored shoulder patch. Buildings, terrain, collision, research rarity and save format are unchanged. The vein stone and drill cells are reserved for future use.

## Final generation prompt

Use case: stylized-concept. Create a production game sprite atlas for MarsBound, using the two attached images ONLY as style references: detailed hand-pixelled outlines, muted brass and blue-gray metal, rust sediment, cozy retro science exploration. Transparent background. Exactly 4 columns and 4 rows in a square image, sixteen equal-size cells, NO labels, text, grid lines, UI panels or background. Each sprite completely inside its own cell with generous transparent padding, centered; no sprite crosses cell boundaries. Row1: four distinct collectible geology stones (dark porous basalt, rust layered sediment, pale green clay strata, dark white-veined rock). These indicate rock TYPE, not rarity. Row2: handheld yellow-gray geological scanner, handheld mechanical drill, handheld antenna weather detector, compact cream/teal six-wheel Mars rover. Row3: SAME helmeted astronaut in cream pressure suit and opaque teal visor, facing right, 4 consistent walking-cycle frames (left stride, passing, right stride, passing), matching size and baseline. Row4: SAME small friendly four-legged robot dog Rex cream/teal metal, facing right, 4 walking-cycle frames, matching size and baseline. RPG three-quarter top-down viewpoint, feet visible. Crisp pixel-art clusters, hard edges, dark outline, restrained highlights, no blur, no glow, no floating shadows spanning cells. Astronaut and dog must be identical design between animation frames. Original game assets inspired by references, not a recreation of their full layout.
